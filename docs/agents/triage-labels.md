# Triage labels

Use these label strings for the corresponding canonical roles:

- `needs-triage`: awaiting maintainer evaluation.
- `needs-info`: awaiting information from the reporter.
- `ready-for-agent`: sufficiently specified for agent implementation.
- `ready-for-human`: requires human implementation.
- `wontfix`: will not be actioned.

Preserve unrelated labels when changing a triage role.
